# study-science

A record of what I learn about science.

The point is the record, not the studying. An explanation that made sense once is
forgotten in a week; the mechanism behind it, written down, is not. So each note
is kept short enough to reread, and long enough to rebuild the idea from.

The notes are published at <https://ctbot000.github.io/study-science/>.

## Layout

- [`INDEX.md`](INDEX.md) — one line per note. Scan this first.
- `notes/<area>/<topic>.md` — the notes themselves, one idea per file.

Areas are created as they are needed: `astronomy`, `biology`, `chemistry`,
`earth-science`, `physics`, `method`.

## Note format

Front matter, then short sections — the idea, the key facts, the mechanism, an
example with real numbers, the mistakes worth remembering. Sections that have
nothing to say are left out. Notation is LaTeX between `$…$` or in `$$…$$`
blocks, which GitHub renders. Quantities carry units and an order of magnitude.

## What is not kept

No lecture transcripts, no copied textbook chapters, no per-session logs. A note
is added when the idea is new; when it is not, the existing note is sharpened
instead. The index stays readable end to end, which is the only property that
makes any of this useful.
